读图指南

  • 三条泳道：三个圆角面板＝三个大模块，面板表头右侧徽标给出该带边数（带内 n · 出 m · 入 k）； ③ 带是全图唯一输出面——跨模块主干流只在这里汇聚。点击面板表头可单带聚焦（Esc 退出）。
  • 分层：跨模块主干流（带→带，实线粗 2.6px + 白色衬底）就是最终流转数据， 只走面板之间的带间竖直轨道，不切面板内部；模块内流（1.5px）在面板内部走线， 默认淡显（可在图例取消「突出主干流」）。走线与卡片/标题/面板边框保持 ≥8px 净空，轨道按源/目标中点分配、互不重叠。
  • 线型：在「主干 / 带内」分层之上再叠语义——实线 = 有代码证据的数据流（含 2026-10-16 第五回合——A1/A2/B1/fit.rds/D2/C1/VSRR → 包函数均已接线）； 虚线 = 规划边（D1b 月度标签、e1/d1a→待建函数）；点线 = 缺口/纸面假设（G1→D1a 的 county→ZCTA 聚合桥）； 灰点线 = 实装资产复用但未接线（VSRR 面尚未进 expected_life_loss）。
  • 屏障：①带中部红色虚线 = 防泄漏屏障。train ≤2025-06 是 fit 唯一可见范围； valid 2025-07..2026-07 只进指标计算，永不入 fit；阶段B 全量重训是一次 受 gate 约束的显式越界（consistency ≤ 1.5，见 fit_price_forecast.R）。
  • 走线规则：带内端口间优先直接连成 S 形平滑曲线；被卡片/标题/面板边框遮挡时自动以圆滑折线绕行 （圆角半径逐级收缩直到净空达标，窄缝处走带贴边惩罚的栅格寻路）；端口按冲突数分散落点，冲突过度时自动溢出到相邻边。 右上角「路由自检」逐点复核 穿框 / 交叉 / 近贴 / 标签重叠 / 主干轨道数 / 用时（端口邻域 12px 为构造性豁免）。
  • 标签与溯源：标签默认悬停显示（图例可勾选「常显」并自动避让）；每条边起点为小圆点、终点为箭头。 悬停连线或节点即高亮相关元素并浮出「源 → 目标」提示；点击连线固定高亮，Esc 或点击空白取消。
  • 节点明细（物理位置、生产者、消费者）见下表；指标数字不进节点，见图底里程碑行。

「数据库逻辑」（数据规则而非表结构）

  1. 缓存优先于 API：prepare.R 先读 b1_monthly_cache.csv，缺失才要求拉全； EIA 限速通过逐州重试背压（Sys.sleep(2 + 3*i)）实现；下游不得绕过缓存。
  2. 切分不可泄漏：2025-07..2026-07 是 valid，fit 内永远是盲区；阶段B 全量重训是一次 受一致性 gate 盯守的显式越界（重训 in-sample 残差 MAD[2025-07..2026-07 池化] ÷ 阶段A valid 残差 MAD ≤ 1.5，结果以 gate_pass 落入 fit.rds；0.657 过门，2026-10-16 重跑）。
  3. grep 锚点即界面：train.R 与评分循环之间的“接口协议”只是 run.log 的四行字符串： mase: / bad_coverage: / coverage: / n_predict:，无类型保证 → 任何改口径动作都会 降级成账本漂移（exp#2/#7 的 coverage 数已经历两次 advance-rule 修订，不可纵向比较）。
  4. provisional 双层声明：B1 43 月中 19 月为 provisional（2025-01→2026-07）；VSRR 全窗口为 provisional（终值将回改）；mortality 允许 provisional 覆盖窗口，但输出必须显式区分“实测/预测 + 已回改/待回改”。
  5. 来源强制（2026-11-18 契约）：任何进入 DAG 输出层的数值不得是无来源硬码； delta_le 只能以显式敏感度参数存在——exp#40 核实结论：无美国 ZIP 级"电价→ΔLE"直接弹性， sensitivity_assumption 附文献区间引注（Richardson BMJ Public Health 2023;1:e000097 情景带 −0.7..−1.6y，非单位电价弹性；Chirakijja NBER WP 25681 方向证据）。
  6. 合成层声明假设（exp#42/43）：州年龄模式=全国年龄模式×m（VSRR 无州×年龄分解）、 abridged life table 约定（ax=n/2、85+ e=1/m）、Δe1→Δe0 可移植性——全部以 sensitivity_assumption 的 DECLARED 标签随行，L1 自检（US m=1 → e0=锚值）为回归锚。
  7. OpenEI 映射非时间序列：A2 是 mapping vintage 2024，唯一套用 3 年的槽位， 接线时须以 provenance 字段（mapping_vintage / as_of，字段名接线时定稿） 标进每个输出行以便日后重估。
  8. 临时产物分层：eia_json/（gitignore）与 run.log（gitignore）、results.tsv（untracked） 都不是入库数据；图中灰色节点专表这一层，凡“实装”结论不依赖它们在 git 树内。
